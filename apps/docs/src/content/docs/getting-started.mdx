## Cài đặt

```bash
pnpm add @vxrerp/sdk
```

SDK có ba entry:

| Import                 | Dùng cho                                                            |
| ---------------------- | ------------------------------------------------------------------- |
| `@vxrerp/sdk`       | `VxrErpClient`, error class, toàn bộ type — chạy ở mọi runtime   |
| `@vxrerp/sdk/node`  | `createVxrErpClient()` đọc env, và `webhooks` để xác minh chữ ký |
| `@vxrerp/sdk/react` | `VxrErpProvider` và các hook React Query                         |

## Tạo client trên server

`createVxrErpClient()` đọc cấu hình từ biến môi trường:

| Biến                       | Ý nghĩa                                               |
| -------------------------- | ----------------------------------------------------- |
| `VXRERP_API_URL`        | Base URL của API, ví dụ `https://billing.example.com` |
| `VXRERP_SECRET_API_KEY` | Secret key, gửi dưới dạng `Authorization: Bearer …`   |
| `VXRERP_MAX_RETRIES`    | Số lần retry tối đa, mặc định `2`                     |
| `VXRERP_TIMEOUT_MS`     | Timeout mỗi request, mặc định `30000`                 |

```ts
import { createVxrErpClient } from '@vxrerp/sdk/node';

const vxrErp = createVxrErpClient();

const customer = await vxrErp.customers.create({
  email: 'khachhang@example.com',
  name: 'Nguyễn Văn A',
  currency: 'vnd',
});
```

Giá trị truyền vào ghi đè env:

```ts
const vxrErp = createVxrErpClient({ maxRetries: 0, timeoutMs: 10_000 });
```

## Tạo client ở mọi runtime

Ngoài Node, dựng `VxrErpClient` trực tiếp với cấu hình tường minh:

```ts
import { VxrErpClient } from '@vxrerp/sdk';

const vxrErp = new VxrErpClient({
  baseUrl: 'https://billing.example.com',
  apiKey: secretApiKey,
});
```

| Option                         | Mặc định           |
| ------------------------------ | ------------------ |
| `baseUrl`                      | `''` (cùng origin) |
| `apiKey`                       | không gửi header   |
| `fetch`                        | `globalThis.fetch` |
| `maxRetries`                   | `2`                |
| `timeoutMs`                    | `30000`            |
| `shouldGenerateIdempotencyKey` | `true`             |

## Cách gọi

Method nằm trên resource, tên method không lặp lại tên entity:

```ts
const customers = await vxrErp.customers.find({ limit: 20 });
const customer = await vxrErp.customers.get('cus_123');
const invoice = await vxrErp.invoices.finalize('in_123');
const clock = await vxrErp.testHelpers.testClocks.advance('clock_123', {
  frozenTime: '2026-10-01T00:00:00Z',
});
```

`get` ném `VxrErpError` khi không tìm thấy; `find` trả về một list, rỗng nếu không có gì. Danh sách đầy đủ ở trang [Resources](/resources/).
