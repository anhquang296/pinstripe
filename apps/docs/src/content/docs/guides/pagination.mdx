Mọi method `find` trả về `ListResponse<T>`:

```ts
interface ListResponse<T> {
  url: string;
  hasMore: boolean;
  data: T[];
}
```

| Tham số  | Ý nghĩa                                        |
| -------- | ---------------------------------------------- |
| `limit`  | Số phần tử mỗi trang, `1`–`100`, mặc định `10` |
| `after`  | Lấy các phần tử **sau** id này                 |
| `before` | Lấy các phần tử **trước** id này               |

Duyệt hết một collection:

```ts
let after: string | undefined;

for (;;) {
  const page = await pinstripe.customers.find({ limit: 100, after });

  for (const customer of page.data) {
    await syncCustomer(customer);
  }

  const lastCustomer = page.data.at(-1);

  if (page.hasMore && lastCustomer) {
    after = lastCustomer.id;

    continue;
  }

  break;
}
```

Danh sách rỗng là một kết quả hợp lệ — `find` không bao giờ ném lỗi vì không có gì để trả.
