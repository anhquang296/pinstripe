---
title: Expand
description: Nhúng object liên quan vào response thay cho id.
sidebar:
  order: 5
---

Mặc định, quan hệ được trả dưới dạng id (`customerId: "cus_123"`). Truyền `expand` để nhận cả object trong cùng response:

```ts
const invoice = await vxrErp.invoices.get(invoiceId, { expand: ['customer', 'subscription'] });
```

Qua HTTP, `expand` là tham số query lặp lại:

```bash
curl "https://billing.example.com/v1/invoices/in_123?expand=customer&expand=subscription" \
  -H "Authorization: Bearer $VXRERP_SECRET_API_KEY"
```

| Object                                                                                                | Field expand được          |
| ----------------------------------------------------------------------------------------------------- | -------------------------- |
| Invoice                                                                                               | `customer`, `subscription` |
| Discount                                                                                              | `customer`, `coupon`       |
| Entitlement                                                                                           | `customer`, `product`      |
| Subscription, Invoice item, Tax ID, Payment intent, Refund, Credit note, Customer balance transaction | `customer`                 |

`expand` áp dụng được cho cả list: mỗi phần tử trong `data` được expand.
