Đăng ký một endpoint để nhận event. Mỗi endpoint thuộc về đúng một module (`billing`) và chỉ đăng ký được event của module đó:

```ts
const webhookEndpoint = await vxrErp.webhookEndpoints.create({
  module: 'billing',
  url: 'https://example.com/webhooks/vxrerp',
  enabledEvents: ['invoice.paid', 'invoice.voided'],
});
```

Mỗi request gửi tới endpoint mang header `vxrerp-signature`. Xác minh nó trên **raw body** — body đã parse lại thành JSON sẽ không khớp chữ ký:

```ts
import { WEBHOOK_SIGNATURE_HEADER, webhooks } from '@vxrerp/sdk/node';

app.post('/webhooks/vxrerp', async (request, reply) => {
  const signatureHeader = request.headers[WEBHOOK_SIGNATURE_HEADER];
  const event = webhooks.constructEvent(request.rawBody, signatureHeader, webhookSecret);

  await handleEvent(event);

  return reply.code(200).send();
});
```

`constructEvent` ném `VxrErpSignatureVerificationError` khi chữ ký sai hoặc quá hạn. Chỉ cần kiểm tra mà không parse thì dùng `webhooks.isSignatureValid(...)`.

Độ lệch thời gian cho phép mặc định là `300` giây (`DEFAULT_WEBHOOK_TOLERANCE_SECONDS`), chỉnh qua tham số `options` cuối cùng.

Delivery thất bại được retry với backoff. Xem lịch sử bằng `vxrErp.webhookDeliveries.find()`.
